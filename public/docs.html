What the product does

AfterHours is an on-chain equity-intelligence + autonomous-execution platform for Solana. While the NYSE closes, the on-chain copies of the same stocks (xStocks/Backed tokenized equities — AAPLx, NVDAx, MSFTx…) keep trading. AfterHours continuously maps the live on-chain price of every tokenized equity against its frozen reference, surfaces the dislocations (the "gap"), and runs the Weekend Gap Vault — real capital that buys the deepest gap while the reference is frozen and unwinds at the open. Every real fill is signed, capped, and visible with its Solscan link.

Weekend Gap Vault (real capital, tiny size)

The winner-shaped capital-utilization product: deposit SOL → arm → while the NYSE reference is frozen the vault buys the deepest discounted xStock (hard-capped ≈$0.25/fill, curated mint allowlist, ≥50bps real gap required — it refuses to buy blind if references are down) → at the open it unwinds to SOL. A 60s keeper runs the state machine (idle → armed → holding → unwind) with no-churn, kill-switch, and min-volume guards.

Autonomous strategy engine (paper)

Plain-English rules (e.g. "rotate to discounted tokenized equities") drive an honest paper ledger — integer micro-units, real fees + slippage, a cost-basis guard that makes phantom profit structurally impossible. 60s server-authoritative loop, every decision logged, dust-filtered alerts.

Live Solana rail

  • GET /api/v3/live/info — wallet address + SOL balance + RPC (honest configured:false when no key).
  • POST /api/v3/live/probe — signs + broadcasts a real 2,000-lamport self-transfer to prove the rail (returns the tx).
  • POST /api/v3/live/swap — SOL → curated xStock, hard-capped ≈$0.60/order + mint allowlist + rate-limited; routes via Jupiter /swap/v1 on api.jup.ag. Never a fabricated fill.

Authentication

  • Wallet auth — self-custody Solana sign-in (challenge → ed25519 verify → session; verified E2E).
  • Privy — managed wallet login, ID-token verified server-side (App Secret never leaves the server).
  • Handle/password accounts + per-user watchlist.

Security & honesty

  • Secrets only in .env (gitignored); API keys redacted from every surfaced error (a leak was caught live and fixed — keys were appearing in public 429 messages).
  • Swap endpoints: mint allowlist + hard value cap + rate limit — a public caller cannot drain the wallet.
  • No fabricated prices or fills — every number traces to a verified live source; paper/real modes are explicit.
  • Ledger guard prevents phantom NAV; vault accrual uses a self-calibrating baseline so pre-existing holdings are never mislabeled as dividends.
